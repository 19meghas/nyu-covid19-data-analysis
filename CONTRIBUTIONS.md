# Project Contributions

This project was originally developed collaboratively by a three-person team as the final project for the **NYU Stern Data Bootcamp in Spring 2020**.

The contribution descriptions below are based on the recovered project notebooks, intermediate working files, and the original project workflow.

The other contributors are currently referred to as **teammates** rather than being named publicly. Their names can be added later after confirming how they would like to be credited.

## Project conception, coordination, and analysis

My contributions centered on the project’s conception, analytical direction, development, and integration.

* Conceived the overall project idea and translated it into the analytical questions and structure used for the final project.
* Coordinated the division of analytical work across the three-person team.
* Developed the project’s global COVID-19 analysis and visualizations.
* Developed the United States and New York City analyses and visualizations.
* Proposed the animated bar-chart race as an additional visualization and coordinated it as a separate workstream.
* Brought the independently developed sections together into the combined project notebook.
* Worked across the different sections to organize the final analytical flow and presentation.

## Teammate — Animated visualization and supporting analysis

One teammate focused on the animated visualization work.

Their contributions included:

* Researching and implementing the animated bar-chart race proposed for the project.
* Preparing and reshaping the confirmed-case time-series data required for the animation.
* Adapting the animation logic to the countries, dates, variables, and presentation used in the project.
* Contributing additional exploratory analytical work during project development.


## Teammate — Regression and financial analysis

Another teammate focused on the regression and financial-market workstreams.

Their contributions included:

* Developing the state-level COVID-19 testing regression analysis.
* Exploring relationships between testing volumes and selected state-level variables, including physician counts, population, income, healthcare spending, and pollution.
* Developing simple and multiple regression models.
* Developing the major financial-market index analysis.
* Developing analysis of selected individual companies.
* Developing the gold-price analysis.

## Restoration work

The current restoration is being undertaken by the contributor responsible for the project’s original conception, coordination, global analysis, United States and New York City analysis, and final notebook integration.

The restoration work includes:

* Reconstructing the project from the recovered 2020 files.
* Identifying the most representative version of the original Spring 2020 submission.
* Organizing the project into a reproducible Git repository.
* Separating historical working files from the polished public-facing project.
* Auditing historical datasets and file dependencies.
* Improving repository and methodology documentation.
* Cleaning and restructuring Python code where necessary.
* Replacing fragile data-handling logic while preserving the original analytical intent.
* Improving visualization design and consistency.
* Clarifying statistical interpretation and analytical limitations.
* Validating the restored workflow against the historical project.
* Recording which changes belong to the restoration rather than the original 2020 analysis.

The purpose of the restoration is to preserve the original work while presenting it in a more reproducible, transparent, and professionally organized form.

It is not intended to rewrite the project as though it had originally been developed with later pandemic knowledge, newer data, or the benefit of subsequent technical experience.
